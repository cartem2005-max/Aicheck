# Проверка постов на приёмы нейросети

Тестовое задание для «Культуры Аналитики». Telegram-бот [@postcheckbotai](https://t.me/postcheckbotai) на n8n: оценивает, насколько пост похож на текст нейросети, показывает найденные приёмы с цитатами и предлагает замены. Раз в сутки проверяет новые посты канала и шлёт сводку подписчикам.

Отчёт для заказчика: [report/otchet.md](report/otchet.md). Как устроено, на одной странице: [report/prilozhenie.md](report/prilozhenie.md).

## Как устроено

```
Telegram → n8n → правила в коде + Claude Sonnet 5.5 → проверка замен кодом → ответ в Telegram
```

- `src/` — вся логика в обычных JS-модулях, без n8n:
  - `linter.js` и `rules.json` — правила для очевидных шаблонов;
  - `explain_fix.js` — разбор по списку из 50 приёмов и проверка каждой замены (числа, даты, названия, отрицания, условия, оговорки, связки, глагол);
  - `safe_fix.js` — что бот правит сам, список короткий;
  - `facts.js` — сверка фактов до и после правки;
  - `bot_core.js` — команды, лимиты, сборка сообщений;
  - `prompts/signs_catalog.md` — сам список приёмов.
- `n8n/templates/` — шаблоны воркфлоу. `n8n/build.js` вставляет модули из `src/` в Code-ноды и собирает `n8n/dist/*.json`.
- `n8n/simulate.js` берёт код прямо из собранных нод и прогоняет его на тестовых данных. Так проверяется, что в n8n работает тот же код, что в тестах.
- `eval/` — скрипты замеров. Итоги лежат в `eval/results/*.md`, главные из них `zones_bot.md`, `ext_detect.md`, `ru_llm.md` и `ru_llm_human.md` (GigaChat и Алиса).
- `data/` — посты канала (публичные, с t.me/s/kultura_analitiki) и тексты нейросети на те же темы. Деление на dev и test лежит в `split.json`. Правила подбирались на dev, цифры в отчёте посчитаны на test.

## Запуск проверок

Нужен Node.js 18+, внешних зависимостей нет.

```
node tests/run.js        # 1427 тестов: правила, факты, защиты замен, сборка сообщений
node n8n/build.js        # собрать воркфлоу в n8n/dist
node n8n/simulate.js     # 120 проверок кода из собранных нод
```

## Чего здесь нет

- Ключей. Ключ Anthropic хранится в credentials n8n, ключ n8n API берётся из переменной окружения в `n8n/deploy.ps1`.
- Адреса сервера n8n и chat_id владельца. В коде вместо них заглушки `your-n8n.example.com` и `YOUR_CHAT_ID`.
- Сырых ответов модели (кэшей). Они большие, а выводы из них есть в `eval/results/*.md`.

## Честно о пределах

- Оценка в середине шкалы (40–50) гуляет от вызова к вызову. Края шкалы держатся.
- Нейросеть, которую попросили писать как человек, бот пропускает в 6 случаях из 36.
- Переписывать текст «под человека» автоматически не получилось. Пробовал четыре способа, оценка после правки падала мало. Поэтому бот правит сам только безопасное, остальное предлагает редактору.
